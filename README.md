# ORFIRA v0.4 — лендинг + кабинеты + API

## Запуск

Node.js 20+. В папке проекта:

```bash
npm install
npm run dev:all
```

Откройте http://localhost:5173/

**Важно:** `npm run dev` запускает только фронтенд. Для сохранения заявок нужен `npm run dev:all` или отдельный `npm run server`.

## Функции

- Лендинг с двумя интерактивными 3D-кольцами и hotspots.
- Manrope подключён через `<link>` в HTML (исправлена ошибка PostCSS).
- Кабинеты преподавателя и ученика (пока с демоданными, без авторизации).
- Форма заявок отправляет POST /api/leads, данные сохраняются локально в `server/data/leads.json`.
- GET /api/health проверяет API.

## Ограничения

Локальный API **не предназначен для публичного развёртывания**: нет аутентификации, антиспама, ограничения запросов, полноценной защиты персональных данных и политики хранения. Не вводите реальные персональные данные при демонстрации. Кабинеты и прогресс пока демо, не подключены к базе.

## Следующие шаги

Реальная авторизация по ролям, база данных, конструктор уроков, хранение GLB/видео, проверка домашних заданий.
