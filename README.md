# 💎 Orfira

**Интерактивная образовательная веб-платформа для обучения ювелирному делу**

Orfira — курсовой проект студентов РГУ им. А. Н. Косыгина, направленный на разработку образовательной платформы, объединяющей видеоуроки, интерактивные 3D-модели ювелирных изделий и систему практических заданий.

Главная особенность платформы — возможность одновременно изучать видеоматериал преподавателя и взаимодействовать с 3D-моделью изделия, рассматривая его конструкцию и отдельные элементы.

**Демонстрация:** [orfira-platform.vercel.app](https://orfira-platform.vercel.app/) · [Вход](https://orfira-platform.vercel.app/#login)

## Функциональные возможности

### Лендинг

- Информация о платформе и её преимуществах.
- Интерактивные 3D-модели ювелирных изделий.
- Видеодемонстрация: 25-секундный фрагмент реального урока с оригинальной заставкой и указанием автора.
- Блоки с тарифами и ответами на вопросы.
- Форма отправки заявки (локальный Node.js API).
- Адаптивное меню с кнопкой входа.

### Кабинет преподавателя

- Управление дисциплинами и уроками.
- Загрузка видео и 3D-моделей; новый урок создаётся без модели по умолчанию.
- Редактор уроков с таймкодами и интерактивными точками (hotspots).
- Создание заданий, просмотр и оценивание работ учеников, комментарии и отправка на доработку.
- Список учеников и фильтрация по учебным группам.
- Две демонстрационные работы со статусом «На проверке».

### Кабинет ученика

- Просмотр дисциплин и уроков.
- Интерактивное изучение 3D-моделей.
- Просмотр видео с оригинальной обложкой и указанием авторства.
- Навигация по восьми этапам урока через Smart Timeline и кликабельные таймкоды начала этапов.
- Выполнение и отправка заданий.
- Просмотр оценок и прогресса обучения.

### Демонстрационная авторизация

Роль ученика или преподавателя закрепляется после входа в рамках текущей вкладки (`sessionStorage`). Переходы по адресам кабинетов и история браузера не должны менять роль. Для смены роли необходимо выйти и войти заново. Это клиентское разграничение интерфейсов, а не серверная защита доступа.

## Запуск проекта

**Требования:** Node.js 20.19+ или 22.12+ и npm.

```bash
git clone https://github.com/nastiik44/orfira-platform.git
cd orfira-platform
npm install
npm run dev:all
```

После запуска необходимо открыть локальный адрес, указанный в терминале. Для запуска только интерфейса используется `npm run dev`, для сборки — `npm run build`. Для локальной обработки заявок требуется `npm run dev:all`.

## Демонстрационные учебные материалы

В текущей версии представлен один реальный урок — **«3D-моделирование кольца с глухим кастом»**.

- **Автор видеолекции:** Саньял Дези.
- **Продолжительность:** 22:23.
- **Программа моделирования:** Rhinoceros 7.
- **Материалы:** видеолекция, итоговая интерактивная GLB-модель кольца, восемь этапов Smart Timeline и практическое задание.

Видеоматериал предоставлен автором и используется с её разрешения в рамках учебного проекта Orfira. Авторство указано в интерфейсе урока, редакторе преподавателя и видеодемонстрации на лендинге.

| Таймкод | Этап |
| --- | --- |
| 00:00 | Начало урока |
| 00:16 | Формирование ТЗ |
| 01:31 | Построение размера кольца |
| 02:30 | Настройка размера камня |
| 07:30 | Построение шинки кольца |
| 12:57 | Построение глухого каста |
| 19:00 | Завершение построения кольца |
| 20:48 | Экспорт 3D-модели и конец урока |

Пока доступна только итоговая 3D-модель. На этапах без собственной модели отображается итоговая модель с пояснением. Промежуточные модели и предметные hotspots будут добавлены по мере подготовки материалов. Урок по крапановой закрепке в текущую версию не включён.

## Текущие ограничения

Orfira находится на стадии функционального прототипа. Используются демонстрационный вход и локальное хранение учебных данных. Встроенные видео и модель поставляются вместе с приложением; загружаемые пользователями медиа хранятся в браузере. Данные разных устройств не синхронизируются.

Полноценная серверная авторизация, общая база данных и облачное хранение учебных файлов не реализованы. Промежуточные модели и hotspots реального урока ещё не подготовлены. Полная сборка и браузерная проверка последней версии требуют завершения.


## Организация разработки

Разработка ведётся с использованием Git и GitHub. Принята следующая схема работы:

- `main` — стабильная версия проекта.
- `develop` — ветка текущей разработки.
- Отдельные функциональные изменения фиксируются коммитами.
- Задачи распределяются между участниками команды.

Для обновления репозитория рекомендуется Git или GitHub Desktop: основной MP4 превышает лимит загрузки через веб-интерфейс GitHub (25 МБ), но меньше 100 МБ. Не публикуйте реальные данные студентов, секреты и учебные материалы без разрешения правообладателей.
