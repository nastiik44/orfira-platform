# Orfira — интерактивная платформа обучения ювелирному делу

React + Vite + Three.js. Учебный прототип РГУ им. А. Н. Косыгина, ИТВТ-424.

## Запуск

```bash
npm install
npm run dev:all
```

> Для проверки только фронтенда: `npm run dev`. Для формы заявки необходим `npm run dev:all` (Node.js API).

## Где что менять

| Что нужно изменить | Файл |
|---|---|
| Тексты навигации, тарифов и FAQ | `src/config/site.js` |
| Тексты и секции лендинга | `src/components/landing/` |
| Шапка и подвал | `src/components/landing/Header.jsx`, `Footer.jsx` |
| Исходный фон главного экрана | `public/design/Background.png` |
| Цвета, отступы, радиусы | `src/styles/tokens.css` |
| Стили лендинга | `src/styles/landing.css`, `landing-polish.css` |
| Стили преподавателя / ученика | `src/styles/teacher.css`, `student.css` |
| Кабинеты | `src/pages/TeacherDashboard.jsx`, `StudentDashboard.jsx` |
| Авторизация / навигация | `src/pages/AuthPage.jsx`, `src/App.jsx` |
| 3D-компоненты | `src/components/three/` |
| Хранение учебных данных | `src/lib/` |

Оригинальные иконки дизайнера: `public/design/icons/`. Не загружайте реальные заявки, `.env`, `node_modules` и рабочие видео в Git.

## Ограничения MVP

Учебные данные живут в `localStorage`, медиа — в `IndexedDB` браузера, заявки — в локальном Node.js API. Аккаунты демонстрационные; для нескольких независимых устройств потребуется серверная БД и авторизация.

### Публикация в GitHub

Создайте **пустой** репозиторий на github.com (не добавляйте README и `.gitignore` через интерфейс). В терминале из папки проекта:

```bash
git init
git add .
git commit -m "Initial Orfira project"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/orfira.git
git push -u origin main
```

Замените `YOUR_USERNAME` своим именем пользователя GitHub. Для запуска после клонирования: `npm ci` и `npm run dev:all`. Не публикуйте реальные данные студентов, видео с персональными данными и секреты.
