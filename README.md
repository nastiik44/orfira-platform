# 💎 Orfira

**Интерактивная образовательная веб-платформа для обучения ювелирному делу**

Orfira — курсовой проект студентов РГУ им. А. Н. Косыгина, направленный на разработку образовательной платформы, объединяющей видеоуроки, интерактивные 3D-модели ювелирных изделий и систему практических заданий.

Главная особенность платформы — возможность одновременно изучать видеоматериал преподавателя и взаимодействовать с 3D-моделью изделия, рассматривая его конструкцию и отдельные элементы.

## Функциональные возможности

### Лендинг

- Информация о платформе и её преимуществах.
- Интерактивные 3D-модели ювелирных изделий.
- Блоки с тарифами и ответами на вопросы.
- Форма отправки заявки.

### Кабинет преподавателя

- Управление дисциплинами и уроками.
- Загрузка видео и 3D-моделей.
- Редактор уроков с таймкодами и интерактивными точками (hotspots).
- Создание заданий.
- Просмотр и оценивание работ учеников.

### Кабинет ученика

- Просмотр дисциплин и уроков.
- Интерактивное изучение 3D-моделей.
- Просмотр видео с навигацией по этапам через Smart Timeline.
- Выполнение и отправка заданий.
- Просмотр оценок и прогресса обучения.

## Запуск проекта

**Требования:** Node.js 20+ и npm.

```bash
git clone https://github.com/nastiik44/orfira-platform.git
cd orfira-platform
npm install
npm run dev:all
```

После запуска необходимо открыть локальный адрес, указанный в терминале.

## Демонстрационные учебные материалы

Совместно с преподавателями ювелирного дела планируется подготовить два интерактивных урока:

1. **Крапановая закрепка камня.**
2. **Глухая закрепка камня.**

Каждый урок будет включать видеозапись преподавателя, соответствующую 3D-модель, этапы обучения, интерактивные пояснения и практическое задание.

## Текущие ограничения

Orfira находится на стадии функционального прототипа. В текущей реализации используются демонстрационный вход и локальное хранение учебных данных.

Полноценная серверная авторизация, общая база данных и облачное хранение учебных файлов пока не реализованы.

## Организация разработки

Разработка ведётся с использованием Git и GitHub.

- `main` — стабильная версия проекта.
- `develop` — ветка текущей разработки.
- Отдельные функциональные изменения фиксируются коммитами.
- Задачи распределяются между участниками команды.
